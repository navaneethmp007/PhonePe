# PhonePe Clone

A 1:1 PhonePe web app clone optimized for iPhone 14 (390x844).

## Deployment

This is a static site. Deploy using GitHub Pages:

1. Push to GitHub
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch** → `main` → `/ (root)`
4. Your site will be live at `https://<username>.github.io/<repo-name>/`

## Features

- Home screen with transfer options, contacts, recharge & bills
- Transaction history with real data
- Search, Scan QR, Alerts pages
- Dark theme matching PhonePe's design
- iPhone 14 optimized viewport
- PWA support (Add to Home Screen)
